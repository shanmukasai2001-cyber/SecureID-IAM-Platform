
# IAM Identity Governance & Access Management Lab

## Project Overview

This project demonstrates practical Identity and Access Management (IAM) concepts through a hands-on cybersecurity lab.

## Objectives

- Identity lifecycle management (Joiner, Mover, Leaver)
- Role-Based Access Control (RBAC)
- User provisioning and deprovisioning
- Access reviews and certifications
- Least privilege enforcement
- Python-based IAM automation
- Audit logging and compliance reporting

## Technologies

- Python
- GitHub
- Microsoft Entra ID concepts
- Active Directory concepts
- CSV and JSON
- IAM security principles

## Project Modules

1. User Lifecycle Management
2. Role-Based Access Control
3. Access Review Automation
4. Identity Governance
5. Audit and Compliance Reporting

## Project Status

In Progress

## Disclaimer

This project uses synthetic identity data and is intended
for educational and portfolio demonstration purposes.
